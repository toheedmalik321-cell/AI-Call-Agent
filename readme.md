# 🤖 AI Call Hub - FYP Project

## Project Overview
AI Call Hub ek intelligent system hai jo chat aur voice calls ke zariye customers se baat karta hai.

## ✨ Features
✅ Web Chat System
✅ AI Agents Management  
✅ PDF/DOCX Upload
✅ Smart Knowledge Search
✅ Call History

## 🛠️ Tech Stack
- Backend: Node.js + Express
- Database: MongoDB
- AI: Gemini + OpenAI
- Frontend: HTML, CSS, JavaScript

### Step 1: Prerequisites (Pehle Ye Install Karo)
